# Licence decision

Status: decided on 3 November 2026. Code and documents are released under the MIT licence (LICENSE). Third party data are not redistributed; scripts download them from their official sources.

## Questions to settle first

1. Public release date: 3 November 2026.
2. Do the datasets we use allow redistribution of derived files? This must come from each official page. TartanGround does not state a licence on its official page, so this is unverified.
3. Third party files (IEEEtran.cls) keep their own licence terms.

## Options

| Option | Effect | Fit |
| --- | --- | --- |
| MIT | Permissive, minimal conditions | Simple, widest reuse |
| Apache 2.0 | Permissive with a patent grant | Suits robotics code that others may build on |
| CC BY 4.0 for documents, with a code licence separate | Attribution required for text | Suits the research text |
| None (all rights reserved) | No reuse without permission | Not chosen |

## Decision

MIT, chosen for the widest reuse.
