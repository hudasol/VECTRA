\section{Deviations from the Plan}
\label{sec:deviations}
All deviations are logged in the repository decision record. (i) Compute: three degradation seeds instead of five, two IMU draws instead of five, trajectories cut at 200 s as before, and no non desert check, because one trajectory costs about 7 minutes of visual odometry per core. (ii) Real rover data: the MADMAX download list requires registration and the Katwijk page was unreachable, so no real rover sequence is used; real data enter only through the sky polarisation check \cite{poughon24} and the aerosol climatology \cite{power}. AERONET was unreachable. (iii) The confirmation visual odometry was computed before the freeze with the frozen Study~2 pipeline; no estimator ran on it before the freeze. (iv) The measured anchored sky table was added before the freeze, after the Marseille check showed that the radiative transfer model is about 15 percent too depolarising in clear sky. (v) After the freeze, before any confirmation result was read, we found that the TartanGround ground poses and IMU carry no roll or pitch, so the frozen confirmation run contains no tilt error; a sensitivity run applies the development tilt model to the confirmation split. The same fact means that an SE(3) filter cannot be exercised on these data, and none was built; neither was an external visual inertial baseline. (vi) The development split had been inspected in Study~2; it was used only for selection. (vii) The protocol listed H1 to H6 for the Holm correction in one section and excluded H6 in another; Holm was applied to the four superiority tests H1, H2, H4 and H5, and the non inferiority tests were decided by their intervals. (viii) The joint oracle diagnostic (true heading and true translation) was added after the confirmation run, on the development split.
